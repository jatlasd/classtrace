# ClassTrace × Fable asset package

This package is intentionally modular. It gives Fable the real product vocabulary and visual DNA without dictating the final scroll choreography.

## Direction represented

The landing-page concept begins stylized and editorial, then gradually resolves into the actual ClassTrace interface:

1. raw teacher observation
2. capture composer
3. teacher-controlled review
4. validated evidence record
5. student timeline
6. recognizable product shell

This is still a conventional landing UX. The assets are designed to support sticky sections, expanding surfaces, restrained parallax, layered transitions, and normal headline/body/CTA content.

## Files

- `01-raw-observation.svg`: human, handwritten starting state
- `02-capture-composer.svg`: simplified but faithful quick-capture UI
- `03-review-unfolded.svg`: review state with editable evidence and structured details
- `04-validated-record.svg`: durable evidence object
- `05-student-timeline.svg`: retrieval and accumulation payoff
- `06-full-product-shell.svg`: realistic final product reveal
- `07-modular-fragments.svg`: transparent transition pieces
- `classtrace-tokens.json`: exact portable color/type vocabulary
- `classtrace-asset-board.svg`: package overview

## Guardrails carried over from the product

- Warm paper, dark ink, restrained rust action color
- Sage means validated evidence
- Blue is for links, tags, and secondary connective meaning
- Teacher judgment is the authority
- Raw note must not visually imply automatic permanent storage
- No generic analytics dashboard, AI sparkle language, glassmorphism, purple gradient, or interchangeable SaaS card grid
- Product UI should become more realistic as the scroll progresses
- Handwriting belongs mainly in the public/editorial layer, not inside the final authenticated interface
- Preserve a reduced-motion route where states crossfade or swap without scroll-bound movement

The SVG text remains editable in vector-capable tools. Fable may treat text differently depending on import behavior, so use the assets primarily as visual ingredients and product-state references.
